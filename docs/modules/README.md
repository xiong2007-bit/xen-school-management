# Module catalogue

Approved modules: tenant onboarding and school settings; students and enrolment; guardians and verified relationships; staff; academic years, terms, grades, classes, streams and subjects; teacher assignments; attendance; assessments, grading and report cards; timetables and calendars; admissions; school finance; parent and optional student portals; communication; public websites and CMS; domains; library; transport; document centre; service desk; reports and analytics; XEN SaaS subscriptions and platform administration.

Each specification should define actors, permissions, workflows, data ownership, validation, audit events, notifications, reports, failure states and acceptance criteria.
