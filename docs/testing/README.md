# Testing strategy

Planned coverage: unit, integration, end-to-end, security, tenant-isolation and performance testing. Vitest and Playwright are the planned tools.

Critical scenarios: cross-school isolation; verified guardian access; role boundaries; admissions lifecycle; attendance corrections; result moderation; payment verification and idempotency; immutable posted transactions; public/private website separation; file permissions; webhook replay; mobile usability; backup restoration and deployment rollback.
