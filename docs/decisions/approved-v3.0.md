# Approved decisions — v3.0

- Product: XEN SCHOOL MANAGEMENT by XEN TECHNOLOGIES.
- Market: Zimbabwe first, then international.
- School types: primary, secondary and combined.
- Model: full commercial multi-tenant SaaS.
- Experiences: custom public school websites, private school workspace, parent/guardian and optional student portals, XEN platform console.
- Website: customisable visual builder using approved components; no arbitrary custom HTML/CSS/JavaScript injection.
- Domains: XEN subdomains and school-owned domains.
- Languages: English initially, Shona, Ndebele and future languages planned.
- Architecture: React + TypeScript, Cloudflare Workers, Supabase PostgreSQL/Auth, RLS, Cloudflare R2, Vercel and Cloudflare.
- Finance: architecture planned up front, implementation phased; school finance separate from XEN SaaS billing.
- Current stage: scaffold and documentation only; no application code or executable configuration.
